# G1 Motion Creator

29자유도 Unitree G1의 참조 모션을 만드는 로컬 편집기입니다. MuJoCo로 전신 IK를 계산하고 Three.js로 실제 G1 메시와 조작 축을 표시합니다. GPU 학습, Isaac Sim, 외부 서버는 필요하지 않습니다.

## 실행

이미 독립 Miniconda 환경과 빌드 결과가 준비되어 있습니다.

```bash
cd /home/kim/motioncreator
./run.sh
```

브라우저에서 **http://127.0.0.1:8765** 를 엽니다. 종료는 서버 터미널에서 `Ctrl+C`입니다. 포트가 사용 중이면 `./run.sh --port 8766`으로 실행할 수 있습니다. 정상 실행에는 Python 서버 하나만 필요하며 Node 개발 서버는 필요하지 않습니다.

같은 포트에서 G1 편집기가 이미 실행 중이면 `./run.sh`는 새 서버를 중복 실행하지 않고 기존 편집기의 주소를 안내합니다. 이때 브라우저에서 안내된 주소를 열면 됩니다.

환경을 직접 활성화하려면:

```bash
conda activate /home/kim/motioncreator/.conda
```

새로 설치할 때는 `./setup.sh`를 실행합니다. Python 3.11 환경, 잠긴 Python/npm 의존성, 프런트엔드 빌드를 설치합니다. 최초 설치에는 인터넷이 필요하고 이후 앱과 모델은 로컬에서 동작합니다. 시스템 ROS의 `PYTHONPATH`가 이 환경에 섞이지 않도록 `run.sh`와 테스트 스크립트가 경로를 분리합니다.

## 상자 태스크 · ARDY / SONIC CPU

상단 **상자 태스크**에서 실제/인식 상자 크기·6D pose·질량·마찰계수를 설정하고, **ARDY 모션 생성 → GEAR-SONIC CPU / MuJoCo 검증 → 결과 재생**을 실행할 수 있습니다. 태스크 설정과 참조 NPZ, 접촉력 로그, 검증 보고서는 `tasks/`에 저장됩니다. 상자를 손에 고정하지 않고 접촉·압착·마찰로 파지를 계산합니다.

CPU용 모델과 `.conda-policy` 환경은 설치되어 있습니다. 새 환경에서는 `./scripts/setup-task-cpu.sh`를 실행합니다. 이미 실행 중인 서버는 종료 후 다시 시작하고 브라우저를 새로고침해야 새 API/UI가 반영됩니다.

**모션 생성 완료와 물리 성공은 별개입니다.** 실제 후보 시험에서 접근 조건 시간 초과와 웅크리기 중 넘어짐을 확인했으며, 기본 팔레타이징 모션의 성공은 아직 확인되지 않았습니다. [사용법·물리 모델·저장 규약·API](docs/box-task-cpu.md)를 참고하세요.

## 편집 순서

왼쪽 **BODY GROUPS** 아코디언 하나에서 29개 관절과 골반·손·발의 IK 지점을 선택합니다. 기존 주요 부위/전체 관절 탭은 통합했습니다. 기본 그룹은 별도 프리셋 생성 없이 항상 제공됩니다.

- 어깨 → 왼/오른 어깨 → pitch·roll·yaw
- 팔꿈치 → 왼/오른 팔꿈치
- 손 → 왼손/오른손 → 손목 roll·pitch·yaw + 손끝 IK 지점
- 허리 → roll·pitch·yaw
- 다리 → 왼/오른 다리 → 고관절 roll·pitch·yaw + 무릎
- 발 → 왼발/오른발 → 발목 roll·pitch + 발바닥 IK 지점
- 골반·루트는 독립 항목입니다. 손·발의 IK 지점은 기존 편집기의 조작점이며 추가 모터 자유도가 아닙니다.

**그룹 이름**을 클릭하면 하위 항목 전체가 선택되고 3D에서도 함께 강조됩니다. **화살표**는 펼치기/접기만 합니다. **하위 관절**을 일반 클릭하면 해당 관절만 선택합니다. **Shift+클릭**은 그룹 또는 관절을 현재 선택에 추가/해제합니다. 일부만 선택된 그룹에는 부분 선택과 선택 수가 표시됩니다. 펼친 상태는 같은 브라우저에서 다시 실행해도 복원합니다.

완전히 선택된 손·고관절·허리·발 그룹은 기존 통합 IK 조작을 유지합니다. 예를 들어 왼손 그룹은 손목 3축과 손 IK 지점이 모두 선택되지만, 회전 목표는 손 방향 하나로 계산하여 중간 관절 방향을 중복 구속하지 않습니다. 고관절·허리는 롤 위치에서 3축 방향을 조정하고, 발 그룹은 발목 롤 위치에서 빨간 roll·초록 pitch 링으로 실제 관절각을 조정합니다. 개별 관절을 선택하면 그 관절축의 단일 회전 링으로 전환합니다. 어깨 등 여러 개별 관절의 각도를 함께 지정하려면 오른쪽 **실제 관절각**을 입력하고 **이 부위 관절각 적용**을 누르세요.

**W**는 위치 IK 이동, **E**는 회전, **F**는 선택 보기입니다. 고정된 부위가 포함된 그룹을 이동하려면 하위 자물쇠를 먼저 해제하세요. 발바닥 지점은 위치와 방향을 고정하며, 나머지는 위치 고정입니다. 모터 각도를 잠그는 기능은 아닙니다. 그룹 조작에서도 기존 고정 조건과 관절 한계를 유지하므로 목표에 도달하지 못할 수 있습니다.

**사용자 지정 프리셋**은 기본 그룹 아래에 유지합니다. 서로 다른 부위를 섞은 사용자 조합을 저장할 수 있으며 기존 프리셋 파일은 자동 변경하지 않습니다.

1. 왼쪽 아코디언에서 그룹 또는 개별 관절을 선택합니다.
2. XYZ 축을 드래그합니다. 오른쪽 목표 좌표를 입력하고 **목표 위치 적용**을 누르거나, 축별 ± 버튼으로 1cm씩 이동할 수도 있습니다.
3. 기본적으로 양발의 위치와 방향이 고정되어 있습니다. 자물쇠로 각 부위를 고정/해제합니다. 손 등 다른 부위는 위치만 고정합니다. 고정된 부위를 직접 움직이려면 먼저 해제합니다.
4. **유연하게 따라오기**에서는 선택한 부위에서 관절 연결 경로가 먼 부위일수록 원래 위치에 더 남습니다. 저항을 높이면 이 성향이 강해집니다. **고정 부위만 유지**에서는 고정하지 않은 부위가 더 자유롭게 움직입니다.
5. 자세가 만들어지면 **자세 추가**로 새 키프레임을 만들거나 **선택 프레임에 반영**으로 기존 프레임을 수정합니다. 드래그한 자세는 자동으로 기존 키프레임을 덮어쓰지 않습니다.
6. 프레임을 선택해 이름, 이동 시간, 순서 등을 편집합니다. 이동 시간은 **이전 프레임에서 선택한 프레임에 도달하는 시간**입니다. 첫 프레임에는 이동 시간이 적용되지 않습니다. 멈춰 있는 구간은 같은 자세를 복제하고 시간을 지정합니다.
7. 재생 버튼으로 모션을 계산·재생하고 하단 슬라이더로 시간을 탐색합니다. 프리뷰는 최대 30fps이며 출력은 15–120fps 중 선택할 수 있습니다.
8. **모션 저장**을 누르면 실행별 전용 폴더를 만들고 Kimodo 호환 `motion.npz`, 36열 `motion.csv`, 의미론적 키프레임과 클립을 보존하는 `project.json`, 재사용 가능한 `environment.json`, `metadata.json`을 함께 저장합니다. 같은 프로젝트 이름도 타임스탬프와 식별자로 폴더를 구분합니다.

상단 **열기**는 편집 프로젝트 JSON과 Kimodo G1 NPZ, 36열 G1 CSV를 지원합니다. NPZ/CSV에는 FPS가 포함되지 않으므로 현재 **출력 FPS** 선택값을 원본 프레임 간격으로 사용합니다. 원본 자세 샘플은 하나의 **모션 클립** 키프레임 안에 모두 보존되며, 클립 이동 시간을 바꿔 전체 재생 속도를 조절할 수 있습니다.

브라우저에는 편집 초안이 자동 저장됩니다. 파일 저장은 별도로 눌러야 합니다. 현재 편집 자세는 프로젝트의 `current_qpos`에 보존되지만 **NPZ는 타임라인에 등록한 키프레임만으로 생성**합니다. 자세 변경 후 반드시 키프레임에 반영하세요. **새로운 모션 만들기**는 기본 서기 자세의 키프레임 하나로 타임라인을 초기화하고 양발을 고정합니다. 프로젝트 이름과 자세 실행 취소 기록도 초기화하며, 디스크에 저장된 모션과 사용자 프리셋은 유지합니다. 필요한 작업은 먼저 저장하세요. **기본 서기 자세**는 타임라인을 유지한 채 현재 편집 자세만 되돌리는 버튼입니다.

카메라: 빈 공간 왼쪽 드래그로 회전, 우클릭 드래그로 이동, 휠로 확대. 정면은 로봇 전방(+X)에서 바라봅니다. 황색 바닥 링은 로봇 무게중심의 바닥 투영 위치입니다.

## 다중 선택·그룹 프리셋·카메라 포커스

- 3D 핸들이나 왼쪽 목록을 클릭한 뒤 **Shift+클릭**으로 부위를 추가/해제합니다. 마지막 하나는 선택 상태로 남습니다. 개별 항목의 일반 클릭은 단일 선택으로 돌아가고, 그룹 이름의 일반 클릭은 해당 그룹 전체를 선택합니다.
- **일반 이동**에서 다중 선택 시 축이 선택 부위의 중심에 나타납니다. 축 드래그, 목표 좌표 입력, ±1cm 이동은 모든 선택 부위의 목표에 같은 이동량을 적용하고 전신 IK를 동시에 풉니다. IK 도달 오차 때문에 실제 부위 간 거리는 미세하게 달라질 수 있습니다. 오른쪽 오차는 선택 부위 중 최대값입니다.
- **좌우 미러 이동**을 켜고 **W**로 좌우 짝을 함께 선택하면 축이 기준 부위에 나타납니다. 기준 부위를 바깥으로 드래그하면 양쪽이 벌어지고, 안쪽으로 드래그하면 가까워집니다. 로봇 골반의 좌우 대칭면을 기준으로 이동량을 반사하므로 로봇이 돌아서 있어도 적용됩니다. 앞뒤·위아래 이동은 양쪽에 함께 적용합니다. 목표 좌표와 ±1cm 버튼도 같은 규칙을 사용합니다. 좌우 짝이 모두 있어야 하며, 회전 모드는 기존 그룹 회전을 유지합니다. 기존 비대칭 자세를 강제로 대칭화하는 기능은 아닙니다.
- **Ctrl+Z**는 자세 실행 취소, **Ctrl+Shift+Z**는 다시 실행입니다. 드래그 전 자세와 고정 상태를 복원합니다. 텍스트·숫자 입력 중에는 입력창의 기본 실행 취소가 동작하며, 계산·드래그·재생 중에는 자세 실행 취소를 막습니다. 타임라인이나 프리셋 변경을 되돌리는 기능은 아닙니다.
- 선택한 부위 중 고정된 부위가 있으면 그룹 이동을 막습니다. 이동 전에 해당 자물쇠를 해제하세요. 다중 선택 중에는 마우스 호버가 선택 목록을 바꾸지 않습니다.
- **사용자 지정 프리셋**에서 이름을 입력하고 새 프리셋으로 저장합니다. 프리셋 선택, 이름·부위 구성 수정, 삭제도 가능합니다. 기본 `양손` 프리셋을 제공합니다.
- 프리셋은 `presets/groups.json`에 저장됩니다. 브라우저를 바꾸거나 서버를 재시작해도 남으며, 다른 모션 프로젝트에서도 사용할 수 있습니다. 저장하는 것은 부위 조합입니다. 자세·고정 상태·관절각은 그룹 프리셋에 포함하지 않습니다.
- 부위를 선택하고 **F**를 누르면 해당 부위를 중심으로 카메라를 맞춥니다. 여러 부위면 모두 보이도록 중심과 거리를 맞춥니다. 텍스트나 숫자 입력 중에는 F 단축키가 동작하지 않습니다. 오른쪽 `선택 부위 보기 F` 버튼으로도 사용할 수 있습니다.
- 부위를 선택한 뒤 **W**는 이동, **E**는 회전 모드로 전환합니다. 회전은 손·발·골반, 단일 팔꿈치·무릎 및 아코디언의 모든 단일 관절에서 지원하며 기존 고정을 자동 해제하지 않습니다. 입력 중이거나 드래그·계산·재생 중에는 모드 전환을 막습니다.

## 회전·29개 관절각 정밀 편집

- **손·발·골반 → 회전**: 회전 링을 마우스로 드래그합니다. 월드/로컬 축을 선택할 수 있습니다. 숫자 입력은 월드 XYZ Euler 각도(도)이며, 축별 ±1° 버튼은 선택한 월드/로컬 축을 따릅니다. Euler 숫자는 같은 방향에서도 표현이 바뀔 수 있으므로 큰 회전은 링을 사용하세요.
- **양손 그룹 → 회전**: 그룹 중심을 기준으로 두 손의 위치와 방향을 함께 회전시킵니다. IK 도달 범위 내에서 목표를 추종합니다. 그룹에 고정된 부위가 있으면 먼저 고정을 해제합니다.
- **손 위치 고정 + 회전**: 단일 손은 위치를 유지하면서 손 방향만 바꿀 수 있습니다. 골반도 같습니다. 발은 위치와 방향을 함께 고정하므로 발을 회전하려면 고정을 해제해야 합니다.
- **팔꿈치·무릎 → W 이동 / E 회전**: 단일 선택 후 이동 축으로 위치를 옮기거나, 실제 관절축에 맞춘 링 하나로 굽힘 각도를 조정합니다. 숫자·±1° 조정도 지원합니다. 손/발 끝을 유지하려면 해당 부위를 고정하세요. 별도 굽힘 방향 모드와 보조 핸들은 제거했습니다.
- **29개 관절각 정밀 조정**: 패널을 펼쳐 슬라이더 또는 숫자로 각도(도)를 수정하고 **변경 각도 적용**을 누릅니다. 모델의 관절 범위 내에서 조정하며, 발 등 고정 조건을 함께 풉니다. 고정과 충돌하는 각도를 강제로 적용하지 않고 오차를 표시합니다.
- 회전한 자세도 키프레임에 반영한 뒤 **모션 저장**으로 저장합니다. 골반 방향은 quaternion 최단 경로로 보간하고, 손·발 방향과 공통 고정을 IK에 반영합니다. 기존 프로젝트도 계속 열 수 있습니다.

**월드 축**은 장면에 고정된 X/Y/Z 방향이고, **로컬 축**은 선택 부위의 현재 방향을 따라 회전하는 축입니다. 골반을 수직으로 내릴 때는 월드 Z, 기울어진 손 자체의 축으로 조정할 때는 로컬 축이 편리합니다. 그룹의 로컬 축은 기준으로 선택된 부위의 방향을 사용합니다. 이 선택은 드래그 축과 ±1° 버튼에 적용됩니다. 팔꿈치·무릎과 29개 개별 관절의 회전은 실제 관절축만 사용하므로 월드/로컬 전환을 비활성화합니다. 위치 숫자·±1cm 버튼과 Euler 숫자 입력은 월드 기준입니다.

편집 중 표시되는 COM/지면 정보는 기구학 참고값입니다. 동적 실행은 별도의 [상자 태스크 / SONIC CPU 검증](docs/box-task-cpu.md)에서 확인합니다. [초기 물리 검증 설계](docs/physics-validation-plan.md)도 참고하세요.

## 타임라인 Physics / GEAR-SONIC 재생

하단 재생 버튼 아래 세로로 배치된 **Physics**와 **GEAR-SONIC** 토글을 설정한 뒤 재생합니다.

- **Physics OFF:** 물리 없이 기존 기구학 모션을 재생합니다. SONIC도 자동으로 꺼집니다.
- **Physics ON / GEAR-SONIC OFF:** 기본 PD 제어로 참조 관절 각도를 추종합니다.
  모터는 작동하지만 균형을 잡는 학습 정책은 없으므로 넘어질 수 있습니다. SONIC 모델 없이 서버의 Python 환경으로 실행됩니다.
- **Physics ON / GEAR-SONIC ON:** 설치된 original-release SONIC ONNX 정책으로 모션을 추종합니다.
  별도 `.conda-policy` CPU 환경이 필요합니다. Physics가 꺼져 있어도 SONIC을 켜면 둘 다 켜집니다.

두 물리 모드 모두 MuJoCo 중력·바닥 접촉·관절 토크를 500 Hz로 계산하며,
관절 목표 갱신 및 SONIC 정책 실행은 50 Hz입니다. 루트를 강제로 고정하거나 이동시키지 않습니다.
타임라인에서 선택한 키프레임의 자세를 초기 상태로 삼아 그 이후 구간만 계산합니다. 첫 키프레임은 전체 모션을 계산하고, 마지막 키프레임은 해당 자세의 유지 구간을 계산합니다.
계산 중 진행률과 **계산 취소**가 표시되며, 완료 후 물리 결과를 재생하거나 시간 슬라이더로 확인합니다.
오른쪽 위에 Physics/GEAR-SONIC 상태, 넘어짐 여부와 관절 추종 오차를 표시합니다.

모드를 바꾸면 이전 계산 결과를 비우고 원본 편집 자세로 돌아갑니다. SONIC만 끄면 Physics는 유지됩니다.
물리 결과는 임시 미리보기이며 원본 키프레임이나 저장 모션을 바꾸지 않습니다.
단일 자세는 해당 자세의 이동 시간 동안 유지합니다. 최대 60초 모션을 지원하며 CPU 계산 시간은
모션 길이보다 길 수 있습니다. 원본 시작 자세·높이를 그대로 사용하므로 불안정한 자세는 넘어질 수 있습니다.
오른쪽 **SCENE OBJECTS**에서 박스·원통·구를 최대 32개까지 추가하고 삭제할 수 있습니다. 각 물체는
이동·회전·크기 기즈모와 숫자 입력을 지원하며 질량, 마찰계수, 색상, 불투명도를 프로젝트에 저장합니다.
**모션 저장** 시 좌표계·단위·중력·지면·모든 장면 물체를 별도 `environment.json`에도 기록하고, `metadata.json`에는 환경 파일의 SHA-256을 남깁니다. `project.json`에도 같은 장면 물체 스냅샷을 유지하므로 프로젝트 하나만 열어도 환경이 복원됩니다.
도형의 크기와 회전을 반영한 최저점이 지면 아래로 내려가면 중심 Z를 자동으로 올려 지면 위에 배치합니다.
Physics 재생에서는 각 물체가 저장된 초기 위치와 방향을 가진 MuJoCo 자유 강체로 생성되어 로봇·손·바닥·다른 물체와 충돌합니다.
계산 결과를 다시 재생하거나 시간 슬라이더를 이동하면 로봇과 물체의 기록된 상태를 함께 표시합니다. 편집 중에는 물체를
시각적으로만 조작하며 매 드래그마다 동역학을 다시 계산하지 않습니다. 단계별 파지 성공 판정과 접촉력 보고서는 별도 **상자 태스크**를 사용합니다.
실시간 외력 조작이 아닌 CPU 사전 계산 후 재생 방식입니다. 서버 업데이트 후 재시작이 필요합니다.

## 출력 형식

**ProtoMotions 연결:** 편집 JSON과 Kimodo 호환 NPZ를 유지합니다. 저장 영역에서 **저장 시 ProtoMotions .motion / .pt 추가**를 선택하면 공식 G1 모델로 변환한 파일과 변환 보고서를 함께 저장합니다. 변환용 독립 Miniconda 환경도 준비했습니다. [사용 방법과 sim2sim 규약](docs/protomotions-integration.md)을 참고하세요. BVH를 거치지 않고 29개 관절을 이름으로 대응하고 대상 모델의 FK를 다시 계산합니다.

프로젝트 형식 식별자는 `motioncreator.g1.v1`입니다. 편집 좌표계는 **오른손 좌표계, +X 전방, +Y 왼쪽, +Z 위**, 단위는 **m / rad / s**입니다. NPZ는 Kimodo G1과 동일하게 `posed_joints`, `global_rot_mats`, `local_rot_mats`, `root_positions`, `foot_contacts`를 저장하며, Kimodo 좌표계인 **+Z 전방, +Y 위**를 사용합니다. `numpy.load(path, allow_pickle=False)`로 읽을 수 있습니다.

| 필드 | 형상 | 의미 |
|---|---|---|
| `posed_joints` | N × 34 × 3 | Kimodo G1Skeleton34 순서의 월드 관절 위치 |
| `global_rot_mats` | N × 34 × 3 × 3 | 관절의 월드 회전행렬 |
| `local_rot_mats` | N × 34 × 3 × 3 | 부모 관절 기준 로컬 회전행렬 |
| `root_positions` | N × 3 | 실제 pelvis 월드 궤적 |
| `foot_contacts` | N × 4 | 왼 뒤꿈치·왼 발끝·오른 뒤꿈치·오른 발끝 접촉 플래그 |

배열은 Kimodo와 같이 위치·회전은 `float32`, 접촉은 `bool`입니다. FPS, 원본 모델 해시, 편집 좌표계와 검증 정보는 같은 저장 폴더의 `metadata.json`에 저장됩니다. 프로젝트 내부 로더는 Kimodo 배열을 MuJoCo `qpos`로 되돌려 기존 시뮬레이션 및 ProtoMotions 변환에 사용하며, 이전 Motion Creator NPZ도 계속 읽습니다.

같이 저장되는 CSV도 Kimodo G1과 동일한 MuJoCo 형식입니다. 각 행은 한 프레임이며 **루트 위치 xyz 3개 + 루트 quaternion wxyz 4개 + G1 관절각 29개**, 총 36열입니다. 좌표계는 **+X 전방, +Z 위**, 각도 단위는 rad입니다.

`foot_contacts`는 Kimodo와 같은 위치·속도 휴리스틱(속도 0.15 m/s 미만, 높이 0.10 m 미만)이며 접촉력 센서나 물리 시뮬레이션 결과가 아닙니다. 발을 옮기는 구간은 끝점 중 하나에서 해당 발 고정을 해제하고 중간 자세를 추가하세요.

## 계산 방식과 범위

- 원본 모델: `/home/kim/unitree_ros/robots/g1_description/g1_29dof.xml`. 사용 메시와 모델을 `assets/g1/`에 복사했습니다. 원본 저장소는 수정하지 않았고 라이선스를 함께 보존했습니다.
- 관절 29개 + 루트 평행이동 3개를 푸는 유계 비선형 최소제곱 IK입니다. 골반 회전 목표를 지정하면 루트 회전 3개도 함께 풉니다. 다른 편집에서는 현재 루트 방향을 유지합니다.
- 선택 부위 목표, 고정 부위, 거리별 저항, 약한 관절 자세 유지 항을 함께 풉니다. 관절 범위는 모델에서 읽습니다. 발바닥 코너에는 바닥 관통 페널티가 있습니다.
- 고정은 수치 최적화이므로 수학적으로 완전한 고정은 아닙니다. 위치 오차 3mm 또는 발 방향 오차 0.015rad를 넘는 드래그 결과는 거부합니다. 목표·고정 오차를 UI에 표시합니다.
- 키프레임 사이에는 5차 시간 보간, 루트 quaternion 최단 경로 보간, 공통 고정 부위와 말단 방향의 IK 투영을 사용합니다. 매 프레임 보간 관절 자세를 기준으로 삼아 관절 해가 갑자기 바뀌는 현상을 억제합니다.
- 박스는 크기와 위치를 지정하는 시각 가이드입니다. 손가락/그리퍼, 파지 구속, 박스 운반 부착, 충돌 회피, 지지 다각형/균형 최적화, 토크·접촉력·하중·속도 한계 검증은 이번 범위에 포함되지 않습니다.
- **실제 로봇에 명령을 전송하지 않습니다.** 이 출력은 전신 제어기 입력으로 변환할 참조 데이터입니다. 기존 WBC/정책의 관절 순서, 정규화, 속도 및 접촉 규약에 맞춘 어댑터와 제어기에서의 실행 검증은 별도 단계입니다.
