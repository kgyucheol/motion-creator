# 정형 파지 모션 생성기

텔레옵 시연 7개 클립에서 좌우 대칭 템플릿을 추출하고, 몸 중심선 위 물체의 좌표로 같은 순서의 클립 7개를 생성한다.
구현: `motioncreator/grasp_template.py`, 템플릿: `motioncreator/templates/pick_cube_bimanual.json`,
엔드포인트: `POST /api/grasp-template/generate` (`object_position`, `object_yaw_deg`, `carry_target`, `fps`).

## 단계와 방식
| 단계 | 방식 | 내용 |
|---|---|---|
| 준비 자세 | 관절 델타 | 시연의 대칭화한 관절 변화 곡선을 현재 자세에 더함 |
| 손벌리기 | 관절 델타 | 같음 |
| 파지점 접근 | 카테시안 | 두 TCP를 물체 상대 파지 자세로 IK 이동. 이동 거리가 크면 시간을 늘림(손 속도 0.15 m/s 이하, 가정값) |
| 파지 | 관절 델타 | 같음. 관절 한계를 넘으면 시연이 손에 한 일(TCP 변위)을 IK로 대신 수행 |
| 몸쪽으로 이동 | 카테시안 | 시연이 운반한 **절대 좌표**(또는 `carry_target`)로 이동. 물체 위치에 따라 상대 이동하지 않음 |
| 목표지점 이동 | 관절 델타 | 같음(한계 시 카테시안으로 대체) |
| 놓고 복귀 | 관절 델타 + 정착 | 시연의 곡선을 따르되 시작 오차를 서서히 없애 시연의 끝 자세에서 끝남 |

원칙: 목적 좌표가 있으면 카테시안, 행위 자체가 목적이면 관절 델타.

## 대칭화
왼팔 관절과 부호 반전한 오른팔 관절(roll·yaw 반전)을 평균한다. 시연은 이 평균과 팔·허리 관절 RMS 11~15° 달랐다.
카테시안 단계의 좌우 목표는 대칭 자세에서 측정한 값을 쓰므로 TCP 좌표계의 정의에 의존하지 않는다.

## 범위와 한계
- 몸 중심선 위의 물체만 지원한다(허리 고정). 중심선에서 벗어난 물체는 접근까지는 풀리지만 검증되지 않았다.
- 물체 중심은 시연 파지 순간 두 TCP의 중점으로 가정한다. 손 개폐 채널이 데이터에 없어 파지는 위치만 만든다. 물체 폭 보정 없음.
- 시연 물체 위치(`contact.mid`) 기준 대략 ±5 cm 안에서 접근과 운반이 도달한다. 앞으로 10 cm 이상 멀면 접근·운반이 `unreachable`로 보고된다.
- 시연 자세가 팔꿈치 한계(-60°)에 가까워 위로 8 cm 같은 이동에서는 파지 단계가 카테시안 대체로 바뀐다.
- 템플릿 추출은 `extract_template(robot, clips)`로 한다(클립 7개, 재생 순서). 시연과의 비교는 원본 비교 고스트로 한다.
